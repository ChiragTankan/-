## ⚙️ Setting Up Locally

Get a local copy up and running to test and run the scripts:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd dsa-in-python
   ```

2. **Set up a virtual environment (Optional but Recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```

3. **Run a module script:**
   ```bash
   python 01_Arrays_and_Strings/basic_operations.py
   ```

## 🛠️ Code Conventions & Best Practices
To maintain clean, interview-ready code, every script adheres to:
* 🐍 **PEP 8 Compliance:** Strictly following clean code guidelines for readable formatting.
* 🕒 **Complexity Analysis:** Every file includes explicit Docstrings mapping out the **Time Complexity** (O(N)) and **Space Complexity** (O(1)).
* 🧪 **Dry Run Assertions:** Built-in `assert` validation statements in the main blocks to test solutions on the fly.
